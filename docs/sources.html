The G / K / R suffixes are General, Kannada-medium and Rural. The seat matrix splits the same grid again into HK and RK rows for Article 371(J). Our four taps — category, Kannada, rural, 371(J) — are not a UX guess. They are the government’s own index, read directly off its own data.

What KEA already asks a candidate for

Our two-field form is not a shortcut we invented. It is KEA’s own minimum, confirmed on four separate portals.

The path to permission

The blocker is a signature, not an API key. Karnataka has already done its half of the work — its certificates are in DigiLocker today.

SourceWhat it provesWhy it matters for us
DigiLocker Terms of Use, Requester cf-media.api-setu.in/resources/ 200 · verified Terms of Service agreement to be signed by ‘Requestor Organization’ before proceeding for Integration. This names the blocker honestly. It is the single document standing between four taps and zero taps. This is the ask.
DigiLocker Requester API Specification v1.12 cf-media.api-setu.in/resources/ 200 · verified The full specification for pulling a citizen’s documents with their consent. The moment this is signed, category, caste, income and 371(J) stop being toggles and become fetched facts.

Method

Each page was fetched with curl, and each quoted string confirmed present in the response bytes with grep -F. PDFs were downloaded and parsed with pdftotext before any claim about page counts or column headers was written. Nothing here is quoted from a search result or a summary. 

# reproduce any row above
curl -s https://keaonline.karnataka.gov.in/dcet_opt_etry_2026_v1/main/index.php \
  | grep -o 'Option Entry CET No'
Standing disclosure

This is a demonstration build running on mock data. It is not affiliated with, endorsed by, or operated by the Karnataka Examinations Authority, and it is not the official DCET portal. No government endpoint is called in production and no candidate data is stored. The sources above describe what a permitted implementation would read from, and what permission it would need first.
